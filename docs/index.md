# Bienvenue
Wiki d'autoformation du collectif Street Medic Marseille: 
!!! warning "Avertissement" 
	Ce wiki complète la formation initiale de 5 h. Il ne remplace ni les soins professionnels ni les secours. En cas d'urgence vitale, appeler le 15 (SAMU) ou le 112.
# Pourquoi ce Wiki ?
Ce wiki a été conçu pour centraliser les connaissances pour le collectifs (et ouvert à tous.tes).
Il a pour but de s'auto-former et/ou consolider ses connaissances. Pour cela plusieurs parties ont été réalisé dans un ordre logique:

1. Démarrer: Défini le cadre, le parcours conseillé, le mode d'emploi du wiki
2. Reconnaître: Identifier ce qui est employé contre nous pour anticiper les blessures
3. Équiper: Choisir la protection adaptée à chaque risque, avant d'y aller
4. Soigner: Savoir quoi faire, dans quel ordre, selon la gravité
5. Agir: Coordonner l'équipe avant, pendant et après l'action
6. Ressources: Affiches imprimables, glossaires, sources
7. Collectif: Qui nous sommes, nos valeurs, comment contribuer
